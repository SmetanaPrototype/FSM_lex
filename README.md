# FSM Lexer (DFA/NFA)

Небольшой лексер на основе конечных автоматов.  
Поддерживает построение NFA по регулярным выражениям, преобразование в DFA, минимизацию и разбор входного текста на токены.

## Возможности

- Построение NFA по регулярному выражению (алгоритм Томпсона)
- Преобразование NFA → DFA (метод подмножеств)
- Минимизация DFA (алгоритм Хопкрофта)
- Генерация лексера по набору правил
- Приоритеты токенов и действия при совпадении
- Простой API для интеграции
