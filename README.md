# FSM

Конечные автоматы на C++23: регулярные выражения → NFA → DFA,
плюс параллельная симуляция. Ручной лексер — как демонстрация
применения.

## Что работает

- Парсер регулярок в AST (`fsm.regex`)
  - литералы `a`, любой символ `.`, классы `[a-z]`, `[^0-9]`
  - группировка `(...)`, альтернатива `a|b`
  - квантификаторы `a*`, `a+`, `a?`
- Построение NFA по алгоритму Томпсона (`fsm.nfa`)
- Симуляция NFA на входной строке
- Преобразование NFA → DFA методом подмножеств (`fsm.dfa`)
- Симуляция DFA
- Параллельная проверка массива строк (`fsm.parallel`, `std::thread`)
- Ручной лексер C++-подобного языка (`fsm.lexer`) — демонстрация

## Статистика

- 182 теста, все зелёные
- 6 модулей C++23 (`fsm.token`, `fsm.lexer`, `fsm.regex`, `fsm.nfa`, `fsm.dfa`, `fsm.parallel`)
- Требуется: Clang 17+, CMake 3.28+, Ninja
